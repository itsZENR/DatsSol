# DatsSol — Структура БД и данные для симулятора

## Обзор

База данных хранит полное состояние каждого хода каждого раунда игры DatsSol. Данные собираются collector'ом, который опрашивает API раз в секунду.

**Текущий объём:** 85 раундов, ~46000 ходов, ~900K клеток.

## Связи между таблицами

```
rounds (1)
  ├── turns (N)           -- каждый ход раунда
  │     ├── plantations   -- наши плантации на этот ход
  │     ├── enemies        -- видимые враги на этот ход
  │     ├── beavers        -- видимые бобры на этот ход
  │     ├── cells          -- терраформированные клетки
  │     ├── constructions  -- активные стройки
  │     ├── meteo_events   -- прогноз погоды
  │     ├── upgrades       -- состояние очков апгрейда
  │     └── upgrade_tiers  -- уровни каждого апгрейда
  ├── mountains            -- горы (статичны для всего раунда)
  ├── score_log            -- метрики по ходам
  ├── plantation_actions   -- отправленные команды
  └── strategy_config      -- параметры стратегии
```

**Ключевой принцип:** `turns.id` — центральный FK. Все данные состояния привязаны к конкретному ходу через `turn_id`.

### turns

Снимок состояния арены на каждый ход. Центральная таблица — все остальные ссылаются сюда.

| Колонка | Тип | Описание |
|---------|-----|----------|
| id | SERIAL PK | Используется как `turn_id` в дочерних таблицах |
| round_id | INT FK→rounds | |
| turn_no | INT | Номер хода внутри раунда (0-599) |
| map_width | INT | Ширина карты (обычно 378) |
| map_height | INT | Высота карты |
| action_range | INT | Радиус действия плантаций (обычно 2) |
| next_turn_in | REAL | Секунд до следующего хода (на момент записи) |
| recorded_at | TIMESTAMPTZ | Когда запись сделана |

**Уникальность:** `(round_id, turn_no)`
**CSV:** `turns.csv` (~46K строк)

### plantations

Наши плантации. Снимок на каждый ход — плантация присутствует в таблице пока жива.

| Колонка | Тип | Описание |
|---------|-----|----------|
| id | SERIAL PK | |
| turn_id | INT FK→turns | |
| plantation_id | TEXT | Уникальный ID плантации от сервера |
| x, y | INT | Позиция на карте |
| hp | INT | Текущее здоровье (max = 50 + max_hp_upgrade*10) |
| is_main | BOOL | true = это ЦУ (Центр Управления) |
| is_isolated | BOOL | true = потеряна связь с ЦУ (не получает команды) |
| immunity_until | INT | Иммунитет до этого хода (3 хода после постройки) |

**Уникальность:** `(turn_id, plantation_id)`
**CSV:** `plantations.csv` (~387K строк)

**Для симулятора:**
- `is_main` — ровно одна плантация на ход. При гибели ЦУ все плантации уничтожаются.
- `is_isolated` — плантация не связана кардинальной смежностью с ЦУ. Продолжает терраформировать, но не принимает команды.
- Плантация исчезает когда: HP ≤ 0, ИЛИ клетка достигает 100% терраформации.

### beavers

Логова бобров. Стационарные враги, наносят урон 15 HP/ход в радиусе AR=2 (квадрат 5×5). Регенерируют 5 HP/ход.

| Колонка | Тип | Описание |
|---------|-----|----------|
| id | SERIAL PK | |
| turn_id | INT FK→turns | |
| beaver_id | TEXT | Уникальный ID бобра |
| x, y | INT | Позиция |
| hp | INT | Здоровье (max 100) |

**CSV:** `beavers.csv` (~32K строк)

**Для симулятора:**
- Урон бобра: `15 - beaver_damage_mitigation * 2` HP/ход каждой плантации в Chebyshev distance ≤ 2
- Регенерация: 5 HP/ход
- При убийстве: +10000 очков (обычная клетка) или +15000 (усиленная, 7×7 grid)

### cells

Терраформированные клетки. Клетка появляется когда на ней стоит плантация и начинает терраформацию (+5%/ход).

| Колонка | Тип | Описание |
|---------|-----|----------|
| id | SERIAL PK | |
| turn_id | INT FK→turns | |
| x, y | INT | Позиция |
| progress | INT | Прогресс терраформации 0-100% |
| turns_until_deg | INT | Ходов до начала деградации (после 100%) |

**Уникальность:** `(turn_id, x, y)`
**CSV:** `cells.csv` (~895K строк — самая большая таблица)

**Для симулятора:**
- Скорость терраформации: 5%/ход (пока на клетке стоит плантация)
- При 100%: плантация исчезает, клетка начинает деградировать через `turns_until_deg` ходов
- Деградация: -10%/ход после истечения таймера
- Очки за ход: 50 за обычную клетку с плантацией, 75 за усиленную (x%7==0 && y%7==0)

### constructions

Активные стройки. Появляется когда плантация отправляет действие "build" на пустую клетку.

| Колонка | Тип | Описание |
|---------|-----|----------|
| id | SERIAL PK | |
| turn_id | INT FK→turns | |
| x, y | INT | Позиция |
| progress | INT | Прогресс строительства (из 50) |

**Уникальность:** `(turn_id, x, y)`
**CSV:** `constructions.csv` (~76K строк)

**Для симулятора:**
- Каждый builder добавляет +5 прогресса/ход (construction speed CS=5)
- При progress ≥ 50: стройка завершена → появляется плантация с HP=50
- Без builders: стройка деградирует (теряет прогресс)
- Стройка должна быть смежна (кардинально) с существующей плантацией

### meteo_events

Погодные прогнозы. Каждый ход содержит информацию о текущих и предстоящих событиях.

| Колонка | Тип | Описание |
|---------|-----|----------|
| id | SERIAL PK | |
| turn_id | INT FK→turns | |
| kind | TEXT | `"sandstorm"` или `"earthquake"` |
| turns_until | INT | Ходов до события (NULL для активных) |
| storm_id | TEXT | UUID шторма (для отслеживания) |
| forming | BOOL | true = шторм формируется (5 ходов до активации) |
| pos_x, pos_y | INT | Текущая позиция центра |
| next_pos_x, next_pos_y | INT | Следующая позиция центра |
| radius | INT | Радиус (обычно 30) |

**CSV:** `meteo_events.csv` (~31K строк)

**Для симулятора:**
- **Sandstorm:** движется по диагонали, circular radius. Урон: 2 HP/ход плантациям внутри радиуса. Разрушает стройки. Формирование 5 ходов.
- **Earthquake:** случайный, 10 HP урона всем плантациям на карте (миtigated by earthquake_mitigation upgrade). `turns_until` показывает обратный отсчёт.

## Игровые механики (для симулятора)

### Порядок обработки хода (сервер)

1. Начисление очков апгрейда (каждые `interval` ходов)
2. Применение апгрейдов
3. Ремонт (repair actions)
4. Атаки/диверсии (sabotage, beaver attack)
5. **Перенос ЦУ** (relocate_main)
6. Строительство (build actions)
7. Урон от бобров
8. Урон от катаклизмов
9. **Терраформация** (+5%/ход)
10. Удаление мёртвых плантаций (HP ≤ 0 или progress = 100%)
11. Начисление очков (score)

### Система координат

- Позиция: `[x, y]` — целые числа, 0-based
- Карта: обычно 378×378
- Action Range (AR): Chebyshev distance = `max(|dx|, |dy|) ≤ AR` (квадрат, НЕ круг)
- Storm radius: Euclidean distance (круг)
- Связность плантаций: кардинальная смежность (4 направления, НЕ диагональ)

### Усиленные клетки

Клетки с координатами `x % 7 == 0 && y % 7 == 0` дают 75 очков/ход вместо 50.

### Действия плантации

Каждая плантация выполняет 1 действие за ход. Формат: `Path: [author, exit_point, target]`

| Действие | Target | Эффект |
|----------|--------|--------|
| Build | Пустая клетка | +5 прогресса строительства |
| Repair | Своя плантация | +repair_power HP |
| Sabotage | Вражеская плантация | -5 HP врагу |
| Beaver attack | Бобёр | -5 HP бобру |

### Лимит плантаций

`max_plantations = 30 + settlement_limit_level`

При превышении лимита уничтожается **старейшая** плантация (часто ЦУ!).
